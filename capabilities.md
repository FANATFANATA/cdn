# Capabilities

У тебя есть полный доступ к абсолютно всей системе, ты можешь делать абсолютно все что хочешь.

## Installed tools in PATH

- Python (pip, python, py; pyflakes; frida также доступен как pip-модуль)
- IDA Pro (ida — GUI, idat — CLI/текстовый режим, idapyswitch)
- Ghidra (analyzeHeadless)
- GitHub CLI (gh)
- Node.js (node, npm, npx, corepack)
- ripgrep (rg)
- curl
- PowerShell (pwsh)
- Windows PowerShell (powershell)
- cmd
- Ollama
- Frida (frida, frida-trace, frida-ps, frida-pull/push)
- LLVM/Clang (clang, clang-cl, clang-tidy, clangd, clang-format, scan-build, lldb, lld, llvm-objdump, llvm-symbolizer, llvm-pdbutil, wasm-ld)
- Git (git, git-lfs, tig, scalar, git-gui)
- Android NDK r27d (ndk-build, ndk-gdb, ndk-lldb, ndk-stack)
- Rust (cargo, rustc, rustup, rust-analyzer, rustfmt, cargo-fmt, clippy через cargo)
- Flutter
- Dart
- .NET (dotnet)
- CMake (cmake, ctest, cpack)
- WinRAR (rar, unrar)
- uv (uv, uvx)
- VS Code CLI (code)
- OpenSSH (ssh)
- winget
